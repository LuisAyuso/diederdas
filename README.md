# Artikel

Android-App zum Üben der deutschen Artikel (der, die, das) mit 2000 häufigen Nomen,
plus 200 Sätze zum Deklinieren im Akkusativ und Dativ.
Pure Rust, UI drawn with [dfui](https://github.com/LuisAyuso/dfui).

```
src/lib.rs          model + UI, android_main
src/deck.rs         word/sentence lists, progress.json persistence
src/srs.rs          scheduler (pure, unit-tested)
data/words.tsv      word list, generated by tools/build_words.py
data/sentences.tsv  case game: sentence with ___, akk|dat, m|f|n|pl (article is derived)
assets/             fonts (Atkinson Hyperlegible, Bricolage Grotesque instanced at 800)
android/res/        launcher icons
```

## Scheduling

Every answer advances a global card counter. A card becomes due once enough cards
have passed since it was last shown: 10 after a wrong answer, 20 × streak after
correct answers (20, 40, 60, …). Among due cards one is picked at random, weighted
by how overdue it is. New words only enter when nothing is due. "Gelernt" means a
streak of 3 or more.

## Development

```fish
cargo test
cargo run          # desktop window
```

## Android

Needs the Android SDK with platform `android-35` (cargo-apk is capped at 35), an NDK,
and `cargo install cargo-apk`, `rustup target add aarch64-linux-android`.

```fish
set -x ANDROID_HOME /opt/android-sdk
set -x NDK_HOME $ANDROID_HOME/ndk/<version>
set -x CARGO_APK_RELEASE_KEYSTORE ~/.android/debug.keystore
set -x CARGO_APK_RELEASE_KEYSTORE_PASSWORD android
cargo apk run --lib --release      # build, install and start on the connected phone
```

`--lib` is needed because the crate also has a desktop binary. The APK lands in
`target/release/apk/artikel.apk`.

Progress is stored in `progress.json` (Artikel) and `progress-faelle.json` (Fälle) in the app's data directory
(`~/.local/share/de.luisayuso.artikel/` on desktop, the app's internal files directory on Android).

## Word list

`python tools/build_words.py` regenerates `data/words.tsv`. It downloads its sources
into `tools/.cache/`:

- Genders: [german-nouns](https://github.com/gambolputty/german-nouns) (Wiktionary, CC BY-SA 4.0)
- Frequency: [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles, CC BY-SA 4.0)
  and the [Leipzig Corpora Collection](https://wortschatz.uni-leipzig.de/) `deu_news_2023_300K` (CC BY 4.0)

The script only keeps nouns with a single gender and ranks them by frequency in both
spoken and written German. It also drops words whose lowercase form is more common, such as
das Ich or das Sein, and anything on a small manual exclude list. Regenerating the list
reorders the words, and saved progress is keyed by position in the list.
